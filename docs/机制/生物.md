# 生物

生物由 **体节** 构成

对应每个生物存在一个主血量值，当血量值小于等于零时，判定对应生物死亡

体节有以下属性：

- 体节血量：当血量清零后，判定该体节被摧毁
- 是否为主要体节：若该体节被摧毁，则主血量直接清零
- 体节联通性：可以理解为该体节与哪些体节联通，该体节被摧毁后，可能会形成若干的联通块，若一些联通块内并不存在主要体节，则该联通块内的所有体节都被判定为摧毁
- 体节判定箱(见后文)

除此之外生物本身还会受到Buff影响

# 实现

类比于 [Item.cs](~/物品/物品特性.md) ，我们用一个 `Entity.cs` 去表示该 GameObject为一个生物，并维护生物的基础状态信息

体节对象上存在一个 `body_part.cs` 以及碰撞箱用于维护体节血量以及检测，layer为 `checkbox`

同时还有 `EntityFeature.cs` 用来描述生物行为

同时每个 `Entity.cs` 都引用一个 `EntityFeature.cs` 的继承类

我们通过继承 `EntityFeature.cs` 的类去自定义不同的生物，需要实现以下的虚函数：

- Refresh_state() : 用于更新生物当前状态信息，比如判定受伤，判定肢体损坏等
- Update() : 自定义，用于更新

还有变量 `Event : Stack<Entity_Event>` 用于维护需要处理的信息


比如一个标准的枪械打击流程是这样的:

枪械射击，raycast 击中对应的一个体节，向 `Event` 中 push 一个包含损失血量，受击体节的事件

之后，调用 Refresh_state() 让其自行决定该如何处理事件
