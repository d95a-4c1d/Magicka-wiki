整体上而言，是一个长方形
玩家从最左端出发，一路到达最右端的终点处
若干区块组合成为”区域“，每个区域内都有不同的生态环境与建筑(注：区域的形状任意，但必须保持联通)

地图中会随机生成若干的建筑群和零散建筑，以及墙和封锁区
越是靠近终点，墙和封锁区就越多

## 墙

高过天际的墙壁，将两个区域分割
每隔若干段就会出现门，需要通过做任务的方式打开门，每扇门可能会有不同的任务，例如

+ 只有人行道的门：仅允许玩家通过而载具无法通过
+ 警报门：拉动开关后吸引敌群，坚守一段时间后打开
+ 封锁门：已经打开的门，但是重兵集结，需要拆除障碍并快速通过

## 封锁区

封锁区是一种动态结构，地方会在此处布置防御工事并集结重兵，需要玩家消耗资源并快速通过

若玩家在某处停留太久，则可能会在周边生成封锁区
