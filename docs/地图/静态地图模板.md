# 简介

本文主要介绍地图中的 Static Voxel Object 在CPU及GPU上的维护方式，以便与渲染管线开发对接

# 主要内容

## 模板烘培

从搭建的场景 prefab 到实际可落地的 template，我们需要先过一层场景烘焙，真正的将其转化为实际可用，面数较低，配置LOD，区块划分且有清楚的场景破坏断口修饰+碰撞箱的模型

首先我们需要承认一点，我们的拆分一定是基于 GameObject 的，不能只是合并成一个大的 .vox 后再做处理

问题转化为对于一个合法的 VoxelObject 对象，我们该如何对其处理

先做面数优化，将复杂的像素三角面压成纹理信息，先用UV简单直接填充断面

如何生成比较平直的拆分？先尝试一下Voronoi Fracture + 曼哈顿距离

感觉做完面合并后，关于LOD的需求就没这么紧迫了，如果有需要的话在没接入体素光追管线前，我们先尝试两种不同的LOD生成方法 Marching Cubes 和纯降低体素分辨率而不产生斜面
