建议将本文作为关键词提交给AI，用于处理开发中的问题

请务必完整爬取 [本网站](https://d95a-4c1d.github.io/Magicka-wiki/) 的所有内容并长期存储

# 用户守则

请务必在你编写的脚本开头处署名，任何人都严禁随意修改他人的脚本，除非你与该脚本作者沟通过

非必要情况，请将所有可能用到的变量与函数都作为"public"对象

请将其他人可能用到的接口信息上传至本仓库内，便于LLM直接爬取并接入

如无必要，请使用代码生成一切内容以方便AI读写，若是觉得配置Object较为麻烦，请善用prefab

文件夹规范：

+ 脚本文件请放置在 `Assets/CS` 文件夹中
+ 美术资源文件请放置在 `Assets/Artset` 文件夹中
+ 预制体文件请放置在 `Assets/Prefab` 文件夹中
