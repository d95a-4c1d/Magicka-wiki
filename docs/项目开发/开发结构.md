# 用户守则

请务必在你编写的脚本开头处署名，任何人都严禁随意修改他人的脚本，除非你与该脚本作者沟通过

非必要情况，请将所有可能用到的变量与函数都作为"public"对象

请将其他人可能用到的接口信息上传至本仓库内，便于LLM直接爬取并接入

如无必要，请使用代码生成一切内容以方便AI读写，若是觉得配置Object较为麻烦，请善用prefab

文件夹规范：

+ 脚本文件请放置在 `Assets/CS` 文件夹中
+ 美术资源文件请放置在 `Assets/Artset` 文件夹中
+ 预制体文件请放置在 `Assets/Prefab` 文件夹中

## 项目级设置

项目中所有系统共享的基础常量应统一放在 `Assets/CS/Project_Setting.cs` 中，不应在每个组件或prefab里重复配置。

当前 `Project_Setting` 至少负责维护体素相关的项目尺度：

+ `VoxelsPerUnit = 16`：1个Unity世界单位对应16个MagicaVoxel体素
+ `VoxelSize = 1 / VoxelsPerUnit`：单个体素在Unity世界中的尺寸
+ 编辑器中的体素对象吸附规则，例如位置吸附、90度旋转吸附、`-1 / +1` 镜像缩放等

因此，`VoxelObject`、建筑模板、城市生成、碰撞和后续破坏系统在需要体素尺度时，都应读取 `Project_Setting`，而不是自行保存一份 `voxelSize` 或 `voxelsPerUnit`。

这样做的目的是保证美术资产、编辑器吸附、模板占地、运行时mesh生成和后续破坏数据始终使用同一套尺度，避免不同prefab之间出现隐蔽的比例偏差。
